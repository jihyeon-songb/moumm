# Phase 0 고정 데이터

2026-10-15 Phase 0 스파이크에서 측정한 인스타그램 링크 13개. 단위 테스트와 LLM 단서 추출 평가의 정답 데이터다.

| 파일 | git | 내용 |
| --- | --- | --- |
| `samples.json` | 커밋 | 링크, 유형, 기대 결과(한 곳 / 여러 곳 / 체인 / 범위 밖), 정답 장소, 메모 |
| `private/captions.json` | **제외** | 캡션 원문 (다른 사람의 게시물이라 저장소에 올리지 않는다) |

## 비공개 캡션

- `.gitignore`의 `/fixtures/**/private/` 규칙으로 제외된다.
- 코드에서는 `lib/fixtures/phase0.ts`로 읽는다. 파일이 없으면 `caption`이 `null`이고, 캡션이 필요한 테스트와 평가는 건너뛴다.
- 다른 컴퓨터에서 쓰려면 이 파일을 직접 옮기거나, `spikes/og-probe`로 다시 수집한다.
- 캡션은 원문을 보관하는 용도로만 쓰고 앱 데이터베이스나 배포물에 넣지 않는다 (설계 문서 9장).
